## Addendum (GraphQL/Auth)

1. GraphQL foundation 확장
   - `/graphql` + `/graphql/ui` 수동 테스트 템플릿 정리
   - `channel`, `channel-post` resolver 응답 필드에서 보안 민감 필드 미노출 회귀 검증
2. 인증 경로 정제
   - GraphQL은 `sid` cookie와 `Authorization: Bearer` 모두 허용
   - `Authorization` 기반 요청은 session 조회 의존 없이 `userId` principal로 처리
   - `/api/v1/auth/me`도 Bearer 지원 추가(기존 cookie 호환 유지)
3. persistence 구조 리팩터링
   - 모듈별 repository 분리
   - 런타임 persistence를 PostgreSQL 중심 구조로 정리
